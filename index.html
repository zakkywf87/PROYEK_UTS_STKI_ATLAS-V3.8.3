Cara Membuka ATLAS Search

Karena kebijakan keamanan browser (CORS), berkas aplikasi tidak dapat dimuat langsung lewat file://.

Cara membuka tanpa ribet:
  1. Klik ganda buka-atlas.bat di folder utama, ATAU
  2. Jalankan npm start di terminal Anda.

Browser akan terbuka secara otomatis di http://localhost:8000.
